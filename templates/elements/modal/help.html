Key Bindings

Movement

  • ↑Previous image
  • ↓Next image
  • Shift + ↑Jump to previous undecided
  • Shift + ↓Jump to next undecided
  • Shift + K / JJump to previous / next undecided
  • J / KNext / previous image

Actions

  • ←Apply left action
  • →Apply right action
  • H / LApply left / right action
  • UUndo last command
  • Shift + AApply queued actions

Modals

  • QShow queued actions
  • IShow image list
  • ?Show help
  • EscClose top modal
  • Ctrl + OOpen directory
